### 문제풀이
dp를 이용하여 i,j지점까지가는 최단 경로의 개수 구하는문제이다.<br/>
dp[i][j]의 값은 `dp[i-1][j]` (바로 위의 위치)와 `dp[i][j-1]` (바로 왼쪽 위치)를 더한 값이다.<br/>
    - 오른쪽 또는 아래로 밖에 못가기 때문<br/>
이때 `효율성테스트`를 통과하려면 문제의 마지막 조건인 `1_000_000_007로 나눈 나머지`를 매 `dp값 계산마다 적용`해야한다.<br/>
> 👉 참고
  `_`는 자바스크립트에서 숫자 구분자로 사용되어, 코드 가독성을 위한 용도일뿐이다. 실제 숫자 값에는 전혀 영향을 주지 않는다.
  ```js
  const a = 1000000007;
  const b = 1_000_000_007;
  //맨 앞이나 맨 뒤에는 안 됨
  //(예: _1000, 1000_ 은 오류)
  ```
