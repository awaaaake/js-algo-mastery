### 문제풀이

x를 y로 만들기위한 최소연산횟수이다.<br/>
연산방법이 3가지로 제한되므로, `3가지 연산 방법을 이용해 만드는 다음 숫자`의 `최소 연산횟수`는 `현재의 최소연산횟수에 + 1`을 하는 것이다.<br/>
- x,y의 범위가 지정되어있으므로 dp의 범위또한 해당 조건을 이용<br/>

### ✳️ dp문제의 핵심
dp문제에서 `dp[i]를 갱신`할 때 `기존의 dp[i]값`과 `새롭게 계산한 후보값` 중 `더 좋은 값`(최솟값과 최댓값 등)을 **선택**해서 대입하는 방식이 핵심이다.
이유<br/>
최적 부분 구조 활용<br/>
- dp는 `작은 문제의 최적해`를 이용해 `큰 문제의 최적해`를 구하는 방식이므로,** dp[i]는 여러 경로를 통해 도달**할 수 있고, **그 중 가장 좋은 경우**만 남겨야한다.
💡 예시 1: 최소 동전 개수 문제<br/>
```js
// 금액을 최소 동전 개수로 만드는 문제
for (let coin of coins) {
    for (let i = coin; i <= amount; i++) {
        dp[i] = Math.min(dp[i], dp[i - coin] + 1);
    }
}
```
dp[i - coin] + 1: 새로운 후보 (이전 금액 + 현재 동전 1개)<br/>
dp[i]: 기존에 저장된 최소 개수<br/>
→ 최소값을 선택<br/>

💡 예시 2: 최장 증가 부분 수열 (LIS)<br/>
```js
for (let i = 0; i < n; i++) {
    dp[i] = 1;
    for (let j = 0; j < i; j++) {
        if (nums[j] < nums[i]) {
            dp[i] = Math.max(dp[i], dp[j] + 1);
        }
    }
}
```
dp[j] + 1: j에서 i로 이어질 수 있는 경우의 길이<br/>
dp[i]: i까지의 최장 증가 수열<br/>
→ 최댓값 선택<br/>
