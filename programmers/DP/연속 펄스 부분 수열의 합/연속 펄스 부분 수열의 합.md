### 문제풀이

전체부분수열을 부분합을 다 계산하는것이x, `이전 상태`를 기반으로 **현재 상태의 최적값을 갱신**하는 방식으로 해결하기 때문<br/>

**문제 핵심**
- 부분 수열의 합을 구할 때, 모든 구간을 일일이 계산하면 O(N^2)시간초과<br/>
-> 현재 원소를 포함하는 최대 펄스 부분합 : 이전까지의 최대값에서 재활용해서 O(N)으로 줄이기<br/>

이전값만 재활용하기 때문에 DP를 정의할 필요는 없지만,
`dp[i] = max(p, dp[i-1] + p)` 이런구조이다.<br/>
즉, `이전상태 + 현재값` 또는 `현재값만` 중 더 큰 걸 고른다.<br/>
- `현재 최적해`는 `cur`에 `전체 최적해`는 `max`에 저장한다.<br/>
- 매번 cur를 구할때마다, max는 조건확인후 갱신한다.<br/>

### dp를 굳이..정의해서 풀이한다면?

```js
function solution(sequence) {
    const dp = new Array(sequence.length).fill(0);
    const dp2 = new Array(sequence.length).fill(0);
    let answer = -Infinity;
    
    for(let i=0; i<sequence.length; i++) {
        //현재 시퀀스값을 두가지 펼스로 나눠서 처리
        let a = (i%2===0 ? sequence[i] : -sequence[i]);//[1, -1, 1,...]
        let b = -a;//[-1, 1, -1,...]
        
        if(i===0) {
            dp[i] = a;
            dp2[i] = b;
            answer = Math.max(dp[i], dp2[i], answer);
            continue;
        }
        
        dp[i] = Math.max(dp[i-1] + a, a);
        dp2[i] = Math.max(dp2[i-1] + b, b);//이전값만 재활용하기 때문에 굳이 dp배열을 정의할 필요없이, 갱신할 변수값 2개만 있으면된다.
        
        answer = Math.max(dp[i], dp2[i], answer);
    }
    return answer;
}
```
