### 문제풀이

**그리디 알고리즘**<br/>

- **지금 순간에 최적의 선택을 하면 전체 결과도 최선이 될 것**이라고 가정하는 방식
- 더 큰수를 만들기 위해, 앞의 작은 수를 지워나가는 것
    - 현재 숫자가 이전 숫자 보다 크면, 이전 숫자들을 지우는게 큰 수를 만드는데 유리함
    - 왼쪽부터 숫자들을 순회하며, 매 순간에 현재의 수를 추가하면서, 더 큰수를 만들기위해 이전의 작은 숫자들을 제거함 -> 그리디
    - 즉, `증가하는 구간`에서 앞선 숫자들이 제거되고 뒤의 더 큰수가 추가되는 것
- 마지막에 k개를 다 제거하지 못한 경우를 대비해, (ex '775421') 끝에 남은 k개를 잘라서 반환
- ex.
```js
number = "4177252841", k = 4
현재 num = 7, stack = [4,1] -> stack = [] -> stack = [7]
현재 num = 5, stack = [7,7,2] -> stack = [7,7] -> stack = [7,7,5]
현재 num = 8, stack = [7,7,5,2] -> stack = [7,7,5] -> stack = [7,7,5,8] (2까지만 제거 가능, 원래 숫자들의 순서를 유지하면서 최대 k를 제거할수있기 때문에, 8이 5보다 크다고 해도 5뒤에 추가)
```
현재(num) 숫자가 이전 숫자들 보다 앞에 추가되는 것은 불가능하다 -> 현재 숫자는 stack 끝에서부터 시작해, 큰 수를 만들 수 있는 가장 최선의 앞 자리 까지 가는 것이다.
