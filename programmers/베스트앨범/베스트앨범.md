### 문제풀이

해시<br/>
`해시(Map)` 기반 구조를 이용해서 `각 장르별 노래 재생 정보`와 `각 장르별 누적 재생 횟수`를 저장한다.<br/>
```js
//각 장르별로 가장 많이 재생된 노래 두개씩 계산
const temp = bestAlbum.get(genre).sort((a,b) => {
    if(a[1]===b[1]) return a[0]-b[0];//재생횟수가 같다면 고유번호가 낮은 노래부터
    return b[1]-a[1];//재생횟수가 큰 노래부터
}).slice(0,2);//최상위 두개 곡을 선정
answer.push(...temp.map((el) => el[0]));
```
