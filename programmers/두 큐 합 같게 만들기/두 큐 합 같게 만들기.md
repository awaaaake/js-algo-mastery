### 문제풀이

두 큐의 원소들의 합을 같게 만들기 위한 최소 연산의 횟수를 계산하는 문제<br/>
두 큐에서 워소를 하나씩 다른 큐로 옮겨 두 큐의 합을 같게 만든다 -> 큐를 하나의 배열로 보고 투 포인터를 사용해 합을 맞춘다.<br/>

큐 한개의 sum이 목표값(half: sum1+sum2/2)이 된다면, 다른 큐는 볼 필요가 없다.<br/>
```js
const q = [...queue1, ...queue2];
```
- queue1과 queue2를 하나의 배열로 이어붙여 q라는 배열을 생성
- 두 큐를 하나의 연속된 큐처럼 다룰 수 있다.
```js
let q1Pointer = 0;
let q2Pointer = queue1.length;
```
- q1과 q2의 포인터를 초기화한다.
💡 포인터의 이동은 곧 cnt의 증가이다.
q2P가 `len부터 2*len까지` 이동할 수 있다면, q1P는 `0부터 2*len까지` 이동할 수 있다.
-> 총 cnt는 `3 * len`까지 가능하다.
- sum1을 하나로 기준잡아서 half보다 작으면 q2의 값을 더하고, half보다 크면 q1의 값을 뺀다.
- 모든 경우를 다 돌았을 때(cnt===3*length), `return -1`
