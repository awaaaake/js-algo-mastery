### 문제풀이

힙(Heap)을 이용하는 문제<br/>
1. heap 구현
    - 정렬 기준이 데이터 1개가 아니다 > 정렬 기준이 여러개 일 때 힙정렬
        - comapre 함수 정의
        ```js
        const compare = (a,b) => {
            //오름 차순 정렬 기준, a가 b보다 작을 때 음수 반환
            if(a.total === b.total) {
                if(a.s === b.s) {
                    return a.num-b.num;
                }
                return a.s-b.s;
            }
            return a.total - b.total;
        }
        ```
        - a가 b보다 `정렬 순서상 앞쪽`이면, `음수`를 반환하도록
        - a가 b보다 `정렬 순서상 뒷쪽`이면, `양수`를 반환하도록
        - compare함수는 heap class를 정의할 때 생성자 함수에 전달
            - `정렬 기준(compare)`를 `외부`에서 유연하게 지정하기 위해 `생성자 인자`로 전달
        ```js
        const compare = (a, b) => {
            return a.total - b.total;
        };

        const heap = new MinHeap(compare);
        ```
    - push함수에서 compare의 반환값이 0`이하`면, 같은것이므로 반복문을 종료
