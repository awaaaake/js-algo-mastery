### 문제풀이

1. 숫자를 이진수로 변환<br/>
2. 이 이진수를 이진트리의 형태로 구성할 수 있는지 확인<br/>
- 이진수 -> 포화이진트리<br/>
    - 현재 이진수의 길이 : n(노드의개수) -> 필요한 최소 이진 트리의 높이 h : n.toString(2).length<br/>
    - bi_tree : 2**h-1이 해당 높이(h)의 포화이진트리의 노드 개수 이므로, 부족한부분 0으로 채우기<br/>
    ```js
    let bi_tree = '0'.repeat(2**m - 1 - n);
    ```
- 만들어진 포화이진트리(bi_tree)를 가능한지 재귀로 검사<br/>
    - checkBTree(bi_tree, 0, bi_tree.length-1)<br/>
- 부모노드가 0인데, 자식노드 중 하나라도 1이면 이진트리x<br/>

```js
function checkBTree (b_str, start, end) {
    const mid = Math.floor((start + end) / 2); // 현재 서브트리의 루트 (부모)
    const left_c = Math.floor((start + mid - 1) / 2); // 왼쪽 자식
    const right_c = Math.floor((mid + 1 + end) / 2); // 오른쪽 자식

    if (start == end) return true; // 리프노드는 OK

    // 부모가 0인데 자식 중에 1이 있으면 이진트리 불가
    if (b_str[mid] === '0' && (b_str[left_c] === '1' || b_str[right_c] === '1')) {
        return false;
    }

    // 왼쪽, 오른쪽 서브트리 각각 재귀 확인
    if (!checkBTree(b_str, start, mid - 1)) return false;
    if (!checkBTree(b_str, mid + 1, end)) return false;

    return true;
}
```
- start ~ end까지의 중간값이 서브트리의 루트 노드<br/>
- 왼쪽 서브트리 구간: start ~ mid - 1 : 이 구간에서의 루트 (왼쪽 자식)은 역시 중간값<br/>
- 오른쪽 서브트리 구간: mid + 1 ~ end : 그 중간값이 오른쪽 자식<br/>
