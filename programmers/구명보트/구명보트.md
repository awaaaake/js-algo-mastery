### 문제풀이

투포인터를 활용한 코드 & 무겨운 사람 기준 : `O(N)`<br/>
```js
function solution(people, limit) {
  people.sort((a, b) => a - b);
  let left = 0;
  let right = people.length - 1;
  let count = 0;

  while (left <= right) {
    const sum = people[left] + people[right];
    //right의 사람을 무조건 태우는 보트라고 기준잡았을 때
    if (sum <= limit) {
      //left 사람이 탈수있으면 같이 타기
      left++;
    }
    right--;
    count++;
  }
  return count;
}
```
- left,right로 본인의 차례가 왔을 때 무조건 결과가 나야함<br/>
- 무거운 사람을 기준잡아서 가벼운 사람이 같이 탈지를 결정하면 됨 -> right--를 하면서 left를 +할지말지 결정<br/>
    - 무거운 사람부터 한 명씩 처리하면서, 가장 가벼운 사람과 같이 탈 수 있으면 태우고, 못 태우면 혼자라도 태운다.

`O(N^2)` 효율성👎코드 & 가벼운 사람 기준 <br/>
```js
function solution(people, limit) {
  people.sort((a, b) => a - b);
  const n = people.length;
  let count = 0;
  let visited = new Array(n).fill(false);

  for (let i = 0; i < n; i++) {
    if (!visited[i]) {
      visited[i] = true;
      const w = people[i];
      let max = null; //현재w와 같이 보트를 탈수있는 최대 무게의 사람의 인덱스
      for (let j = i + 1; j < n; j++) {
        if (!visited[j]) {
          const w2 = people[j];
          if (w + w2 > limit) break;
          max = j;
        }
      }
      if (max) visited[max] = true;
      count++;
    }
  }
  //if 20,30,70,80 -> 20+80 / 30+70
  return count;
}
```
- 가벼운 사람 먼저 태우고, 같이 탈수있는 가장 무거운 사람 찾기 -> 매번 그 다음부터 끝까지 일일이 훑어보면서 이중 반복문이 돼서 최악의 경우 `n*n만`큼 비교해야한다.<br/>
