### 문제풀이

공유기 사이 거리의 최솟값 : 1, 최댓값 : Math.max(...pos)<br/>
`가장 인접한 두 공유기 사이의 거리` mid를 최대한 키워가는 이분탐색을 진행한다.

```js
let left = 0;
let right = pos[pos.length - 1];
```

해당 간격을 기준으로, 공유기를 배치해본다.

```js
let prev = pos[0];
let cnt = 1;
for (let cur of pos) {
  if (cur - prev < mid) continue; //배치x
  prev = cur; //배치
  cnt++;
}
//일단 배치해보고
if (cnt >= C) {
  //mid이상의 간격으로 전부 배치가능하다면
  //간격을 더 넓혀본다
  left = mid + 1;
} else {
  //간격을 좁혀서 C개의 공유기를 설치할 수 있도록
  right = mid - 1;
}
```

```js
console.log(right);
```

마지막으로 조건을 만족하는 `가장 인접한 두 공유기 사이의 최대 거리` right를 출력한다.
