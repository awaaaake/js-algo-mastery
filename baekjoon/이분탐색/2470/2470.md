### 문제풀이

이 문제는 투포인터 풀이가 적합하지만, 이분탐색도 가능하다<br/>
- 배열의 값을 순회하면서 현재의 x와의 절댓값 합이 0에 가장 가까운 경우를 찾는다.<br/>
- 이분탐색의 시간복잡도 : O(NlogN) 각 i마다 log N 탐색을 하므로
### 투포인터로 풀 경우

```js
arr.sort((a, b) => a - b);
let left = 0;
let right = N - 1;
let best = Infinity,
  a = 0,
  b = 0;

while (left < right) {
  const sum = arr[left] + arr[right];
  if (Math.abs(sum) < best) {
    a = arr[left];
    b = arr[right];
    best = Math.abs(sum);
  }

  if (sum < 0) {
    left++;
  } else {
    right--;
  }
}

console.log([a, b].sort((a, b) => a - b));
```
- 시간복잡도 : O(N) 배열 정렬 후, 한번의 선형 스캔으로 끝
