### 문제풀이

이분탐색<br/>
이분탐색 while문의 조건 : while(left<=right)<br/>

```js
function binarySearch(arr, target) {
  let left = 0;
  let right = arr.length - 1;

  while (left <= right) {
    // ★ 종료 조건
    const mid = Math.floor((left + right) / 2);

    if (arr[mid] === target) return true;
    else if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }

  return false;
}
```

왜 while(left<=right) 인가?<br/>

- left === right 상황에서도 mid 계산 → 마지막 원소 확인이 가능
- 만약 조건을 left < right로만 하면, 마지막 원소는 확인하지 못하고 종료될 수 있습니다.
ex. 배열: [1, 3, 5], 찾을 값(target): 5<br/>
```js
올바른 조건 (while (left <= right))
left=0, right=2
mid=1 → arr[1]=3 < 5 → left=2
left=2, right=2  (범위에 아직 원소 하나 남음)
mid=2 → arr[2]=5 → 찾았다! (성공)
```
- 마지막 원소(인덱스 2)도 검사 가능.
```js
잘못된 조건 (while (left < right))
left=0, right=2
mid=1 → arr[1]=3 < 5 → left=2
이제 left=2, right=2
조건: left < right → 2 < 2 은 false → 반복문 종료
→ arr[2] = 5 확인도 못 하고 끝남 (실패)
```
✅ 즉, left < right만 쓰면 탐색 범위가 원소 1개 남았을 때 그걸 확인하지 않고 종료해버린다.
