### 이분탐색

경계를 포함하는 구간 [lo, hi]을 잡은뒤 구간의 길이를 절반씩 줄여나가며, lo,hi이 경계 지점에 위치하도록하는 것
- 이분탐색이 끝난뒤 lo 다음 칸은 hi 즉, lo + 1 == hi
ex. `[1, 50]`에서 숫자 `28`을 찾는 이분탐색
-> `[1, 50] -> [25, 50] -> ... -> [27, 28]`로 lo, hi를 줄여나간 뒤 `hi = 28`을 찾아주면 된다.
-> 만약 데이터가 100만개라면?
    - 만약 카드가 `100만장` 있었다고 하면 특정 카드를 하나하나 앞에서부터 찾으면 `최대 100만번의 연산`이 필요하지만, 이분 탐색을 이용하면 `2^20 >= 1,000,000`이기 때문에 `최대 20번의 연산`으로 원하는 카드를 찾을 수 있다.

## 두가지 패턴
### 1. 정확한 값을 찾는 경우
= target이 배열안에 있는지 여부
-> 반복문 조건 : while(left<=right)
- 이유 : 마지막 원소까지 다 확인해야함.
- mid에서 정확히 찾으면 반환
- ex.백문 10815 '이 값 있니?'

### 2. 경계값(최소/최대 인덱스)을 찾는 경우
= 조건을 처음/마지막으로 만족하는 위치 -> lower bound/ upper bound<br/>
-> 반복문 조건 : while(left<right)
- 여기선 mid를 반환x, left/right 자체가 답이 됨
```js
function lowerBount(arr, target) {
    let left = 0; ,right = arr.length;
    while(left < right) {
        let mid = Math.floor((left + right) / 2);
        if (arr[mid] < target) left = mid + 1;
        else right = mid;
    }
    return left; //또는 right
}
```
- target 이상이 처음 나타나는 인덱스를 반환하는 함수
- 마지막에 left/right가 경계값이 됨

<정리>
값 탐색 (정확히 존재 여부 확인)
- while (left <= right)
- 답은 mid에서 나온다.
경계 탐색 (위치/조건 만족하는 최소·최대 찾기)
- while (left < right)
- 답은 left 혹은 right에 남는다.
