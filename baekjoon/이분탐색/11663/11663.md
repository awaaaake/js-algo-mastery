### 문제풀이

```js
const [N, M] = input[0];
const points = input[1];
points.sort((a, b) => a - b);
const lines = input.slice(2);

for (let [s, e] of lines) {
  //line을 넘어가지않는 점좌표의 최소값과 최대값 찾기
  let left = 0;
  let right = N - 1;

  let lower = N;
  let upper = -1;

  while (left <= right) {
    let mid = Math.floor((left + right) / 2);
    if (points[mid] >= s) {
      lower = mid;
      right = mid - 1;
    } else {
      left = mid + 1;
    }
  }

  left = 0;
  right = N - 1;

  while (left <= right) {
    let mid = Math.floor((left + right) / 2);
    if (points[mid] <= e) {
      upper = mid;
      left = mid + 1;
    } else {
      right = mid - 1;
    }
  }

  const count = upper - lower + 1;
  console.log(count > 0 ? count : 0);
}
```
- 이분탐색 문제<br/>
- 선분의 양끝점 범위 내를 만족하는 point의 최소위치와 최대위치를 이분탐색으로 각각 찾는다.<br/>
  - 최대위치 - 최소위치 + 1 = 선분내 포함된 점의 개수<br/>
  - 초기 lower, upper의 값을 유효하지 않은 값으로 설정
    - lower = N - 1, upper = 0 ✖️(범위 내에 점이 하나도 없을 때 오작동할 수 있음)
    - lower = N, upper = -1
