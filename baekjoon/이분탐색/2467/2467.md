### 문제풀이

- 최대로 나올 수 있는 값 (100000000+1000000000)인 2000000000
- 한 배열에서 두요소의 합을 더해서, 절댓값이랑 비교
 - left를 for문으로 순차적으로 선택하고, 나머지 지점의 right는 while문을 통해 이진탐색으로 찾는다.
- left의 범위는 0부터 N-2까지
```JS
for(let i=0; i<N-1;i++){//O(N)
    let start = i+1;
    let end = N-1;
    while(start<=end){//O(logN)
        let mid = Math.floor((start+end)/2);
        let sum = liquidsArr[mid] +liquidsArr[i]
        if(Math.abs(sum) < abs){
            abs = Math.abs(sum);
            ansLeft = liquidsArr[i]
            ansRight = liquidsArr[mid]
        }
        if(sum===0){
            break
        }else if(sum>0){
            end = mid - 1;
        }else{
            start = mid + 1
        }
    }
}
console.log(ansLeft, ansRight);
```
시간복잡도 : 반복문 도는 O(N) * 이진탐색O(logN)이 라서 O(NlogN)
### 투 포인터
- 배열에서 두요소를 양 끝에서부터 선택에해서 범위를 좁혀간다.
```js
const input = require("fs")
  .readFileSync("./baekjoon/example.txt", "utf-8")
  .toString()
  .trim()
  .split("\n")
  .map((row) => row.split(" ").map(Number));

const [N] = input.shift();
const arr = input.shift();
let left = 0;
let right = N - 1;
let answer = [2000000000, 0, 0]; //각 용액의 특성값의 합, 특성값..

while (left < right) {
  //서로다른 두 용액이어야함
  const sum = arr[left] + arr[right];
  answer =
    Math.abs(sum) < answer[0] ? [Math.abs(sum), arr[left], arr[right]] : answer;
  if (sum === 0) {
    break;
  } else if (sum > 0) {
    right--;
  } else if (sum < 0) {
    left++;
  }
}

console.log(answer[1], answer[2]);
```
- `sum`이 아닌 `Math.abs(sum)`을 answer로 설정해야하는 이유: Math.abs(sum)이 0이고, answer(`sum`)가 -1이면 전자가 답이 되어야한다.
