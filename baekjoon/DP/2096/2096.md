### 문제풀이

dp 문제이다.<br/>
한 행씩 내려가면서 0, 1, 2 각각의 열로 내려왔을 때 [최댓값, 최솟값]을 구하면된다.<br/>
0번째 열의 값을 결정하는 이전 열 : 0, 1<br/>
1번째 열의 값을 결정하는 이전 열 : 0, 1, 2<br/>
2번째 열의 값을 결정하는 이전 열 : 1, 2<br/>

### 코드 개선
처음에는 dp를 `3차원 배열` -> `N행, 3열, [최대, 최소]`로 선언했다.<br/>
하지만 DP는 매번 `이전 DP값(이전 행의 DP값)`을 기준으로 갱신되므로, DP를 N행으로 초기화할 필요가 없다.<br/>
따라서 DP를 [[0,0], [0,0], [0,0]] 2차원 배열로 초기화하면 된다.
