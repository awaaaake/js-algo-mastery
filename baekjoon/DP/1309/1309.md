### 문제풀이

0번째 ~ N-1번째 줄까지 사자를 배치하는 경우의 수를 더해나가는 문제<br/>
사자를 0마리 배치하는 경우(1) + 사자를 1마리 배치하는 경우(2)에서 시작된다.<br/>
`dp[i][0]`은 `dp[i-1][0] + dp[i-1][1]`이고,<br/>
`dp[i][1]`은 `dp[i-1][0] * 2`(왼쪽 또는 오른쪽에 배치하는 2가지 경우를 곱한다.) `+` `dp[i-1][1]`(한쪽에만 배치하면 그 다음줄에 한마리가 세로로 겹치치않는 칸에 자연스럽게 배치된다.)

### 유의할 점
문제조건 : 사자를 배치하는 경우의 수를 9901로 나눈 나머지를 출력하여라.<br/>
-> 최종합계에서만 % MOD를 하면 안된다.<br/>
-> `E[i] = E[i-1] + F[i-1]`에서 E[i-1]와 F[i-1]이 이미 둘다 엄청 큰 수라면 덧셈 결과는 더 큰수가 된다.<br/>
**자바스크립트는 정확히 표현가능한 안전 정수 범위**가 **10^15**까지인데, DP에서 N이 커지고 MOD를 적용하지않으면, 중간값이 이범위를 넘어가버려 **정확도가 깨질 수 있다.**<br/>
-> 정수범위를 유지하면서 DP값을 구해나가기 위해, **매 연산 결과**를 **MOD로 줄이면** 값이 항상 0 ~ MOD-1 범위 안에 있어 **안전한다.**<br/>
`(A+B) mod M = (A mod M + B mod M) mod M`
