### 문제풀이

서로 다른 n종류의 동전을 사용해 k를 만드는 경우의 수(**조합**의 수)를 구하는 문제<br/>

조합은 다음과같이 풀이한다.<br/>
```js
for (let coin of coins) {
  for (let j = coin; j <= k; j++) {
    dp[j] += dp[j - coin];
  }
}
```
- 서로다른 종류의 코인을 순회하면서, <br/>
- 각 경우에 대해
j=coin 금액부터 k금액 까지 경우의 수를 계산한다.<br/>
- dp[j]는 `dp[j-coin]을 구하는 경우`의 각각에 `coin`만큼씩 더하면 되므로, dp[j] += dp[j-coin]<br/>
ex.<br/>
coin = 1 인 경우, <br/>
k=3은 dp[2]을 구하는 경우의 수 각각에 코인 1를 더할수있다. -> dp[3]+=dp[2]<br/>
coin = 2 인 경우, <br/>
k=3은 dp[1]을 구하는 경우의 수 각각에 코인 2를 더할수있다. -> dp[3]+=dp[1]<br/>

### 참고
순서를 고려하는 **순열**의 경우라면, for문의 순서를 뒤집으면 된다.<br/>
```js
for (let j = 1; j <= k; j++) {
    for (let coin of coins) {
        if(j-coin >=0) {
            dp[j] += dp[j - coin];
        }
    }
}
```
