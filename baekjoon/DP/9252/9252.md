### 문제풀이

LCS문제로 dp[i][j]는 배열 A의 첫 i개 원소와, 배열 B의 첫 j개 원소의 최대 공통부분수열의 길이를 구하는것이다.<br/>
이때 dp의 길이는 N+1로  설정하고(1부터 시작), 문자열 인덱싱은 0부터 시작한다.<br/>
dp자체에 문자열을 저장해야한다.<br/>
```js
for (let i = 1; i < n + 1; i++) {
  for (let j = 1; j < m + 1; j++) {
    //i,j는 몇번째글자인지를 의미
    if (A[i - 1] === B[j - 1]) {
      dp[i][j] = dp[i - 1][j - 1] + A[i - 1];
    } else {
      if (dp[i - 1][j].length > dp[i][j - 1].length) {
        dp[i][j] = dp[i - 1][j];
      } else {
        dp[i][j] = dp[i][j - 1];
      }
    }
  }
}
```
