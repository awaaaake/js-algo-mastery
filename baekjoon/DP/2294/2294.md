### 문제풀이

서로 다른 n종류의 동전을 사용해 k를 만드는 최소 동전의 개수<br/>
백준 2293문제와 유사하지만 다른 풀이<br/>

**초기화**<br/>
dp 전체를 Infinity로 초기화<br/>
dp[0] = 0;<br/>

**중간풀이**
기본적으로 for coin -> for j로 순회하되,<br/>
```js
dp[j] = Math.min(dp[j-coin]+1, dp[j]);
```
- 최솟값을 구해나가는 과정이므로, 기존의 dp[j]와 비교해서 대입한다.<br/>
- 각 dp[j]는 dp[j-coin] 즉 j-coin을 만드는 최소 동전의 개수에 coin의 동전 1개를 더하는 총 개수와 기존의 dp[j]중 최솟값을 대입한다.

**최종출력**
문제조건 : `불가능한 경우에는 -1을 출력한다.`<br/>
```js
console.log(dp[k] === Infinity ? -1 : dp[k]);
```
dp[k]가 Infinity인 경우, 해당 k를 만들수없다는 뜻 -> -1 출력<br/>

### 예제<br/>
k: 15<br/>
coins: [1,5,12]<br/>

**현재 coin이 5까지 순회중일 때,**<br/>
dp[12] = Math.min(dp[12-5] + 1, dp[12]); -> 4(1+1+5+5)<br/>
dp[7] = Math.min(dp[7-5] + 1, dp[7]); -> 3(1+1+5)<br/>
dp[2] = Math.min(dp[2-1] + 1, dp[2]); -> 2(1+1)<br/>

**현재 coin이 12인 경우**<br/>
dp[12] = Math.min(dp[0] + 1, dp[12]) -> Math.min(1, 4) -> 1(12)
