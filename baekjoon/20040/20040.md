### 문제풀이
유니온-파인드<br/>
원래 유니온 파인드는 최소스패닝 트리를 만들때, 연결되는 두 노드의 루트 노드를 찾아서 루트 노드끼리 합치는함수이다. 이때 이미 루트 노드가 같으면(같은 집합에 속하면) 두 노드를 연결할 필요가 없다.<br/>
💡반대로, 루트노드가 같을 때 새로운 간선을 추가하면 사이클이 생긴다.<br/>
**<정리>**<br/>
✅ 유니온-파인드를 활용하는 주요 알고리즘
1. 크루스칼 알고리즘 - 최소 스패닝 트리(MST) - 간선 추가 전에 사이클이 생기는지 확인 (MST는 사이클이 없어야 함)<br/>
2. 사이클 검출 - 무방향 그래프에서 사이클이 있는지 확인	- 새로운 간선 추가 시 같은 집합이면 사이클!<br/>

### 사이클 검출하는 법
1. 유니온 파인드<br/>
2. dfs<br/>
```js
class Graph {
  constructor(vertices) {
    this.V = vertices; // 정점 개수
    this.adj = new Map(); // 인접 리스트 (그래프 저장)
  }

  // 간선 추가 (양방향)
  addEdge(v, w) {
    if (!this.adj.has(v)) this.adj.set(v, []);
    if (!this.adj.has(w)) this.adj.set(w, []);
    this.adj.get(v).push(w);
    this.adj.get(w).push(v);
  }

  // DFS를 활용한 사이클 탐지 함수
  dfs(v, visited, parent) {
    visited[v] = true; // 현재 노드 방문 처리

    for (let neighbor of this.adj.get(v)) {
      if (!visited[neighbor]) {
        // 방문하지 않은 노드라면 DFS 수행
        if (this.dfs(neighbor, visited, v)) {
          return true;
        }
      } else if (neighbor !== parent) {
        // 방문한 노드인데 부모가 아니면 사이클 존재
        return true;
      }
    }
    return false;
  }

  // 그래프에 사이클이 있는지 확인하는 메인 함수
  isCyclic() {
    let visited = Array(this.V).fill(false);

    for (let i = 0; i < this.V; i++) {
      if (!visited[i]) {
        if (this.dfs(i, visited, -1)) {
          return true;
        }
      }
    }
    return false;
  }
}

// 테스트
const g = new Graph(5);
g.addEdge(0, 1);
g.addEdge(1, 2);
g.addEdge(2, 3);
g.addEdge(3, 4);
g.addEdge(4, 1); // 사이클 생성

console.log(g.isCyclic()); // true (사이클 존재)
```
### DFS vs. 유니온-파인드
- 한 번에 그래프를 주고 사이클을 찾을 땐 DFS<br/>
- 간선을 하나씩 추가하면서 사이클을 찾을 땐 유니온-파인드<br/>
1. DFS (깊이 우선 탐색) - O(V + E) - 그래프를 탐색하며 바로 찾을 수 있음 - 재귀 호출로 인한 오버헤드<br/>
2. 유니온-파인드 - O(M α(N)) ≈ O(M) - 매우 빠름 (거의 O(1)), 간선을 추가하면서 즉시 판단 가능 - 	초기 구조 설정 필요<br/>
