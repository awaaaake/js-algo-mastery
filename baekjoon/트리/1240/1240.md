### 문제풀이

dfs를 활용해 트리의 노드간 거리를 구하는 문제<br/>

- 지름 구하는 문제와 유사
- 현재 노드의 이웃 노드를 탐색
  - 목표노드에 도달했을 때, dist 반환
  - 다음노드를 순회하며 거리를 업데이트한 dfs를 새롭게 순회
  - **만약 dfs의 결과가 undefined가 아니면 그 즉시 반환**
  ```js
  for (let [next, cost] of graph[node]) {
    if (!visited[next]) {
      const result = dfs(next, dist + cost, target);
      if (result !== undefined) return result; // ✅ 찾으면 반환
    }
  }
  ```
- 이웃노드에서 dfs를 순회한 결과, target을 찾지 못하면 undefined를 return
