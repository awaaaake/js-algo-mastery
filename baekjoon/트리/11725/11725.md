### 문제풀이

이 문제는 트리탐색을 활용해서 노드의 부모를 찾는 문제이다.
노드들을 순차적으로 탐색하면서, 각 노드의 부모노드를 기록한다.

- BFS를 활용하여 트리구조를 탙색한다.
- 이때 큐 자료구조를 활용하여 탐색을 진행한다.
- 부모노드를 체크한 노드라면 탐색을 건너뛴다.

1. 트리의 노드와 간선 정보를 순회하면서 각 노드의 연결정보를 인접리스트의 Map 구조로 저장한다.
2. queue를 사용해 bfs 탐색을 수행한다.
3. 탐색중 방문한 노드의 부모를 parents 배열에 기록한다.
4. 부모를 기록하고, 방문한 노드를 큐에 추가한다.

**사용된 자료구조**
- Map:트리의 인접 리스트를 저장하는 데 사용
    - 각 노드의 연결된 노드들을 효율적으로 저장 및 접근
- Queue:BFS 탐색에서 노드 방문 순서를 관리
- Array:parents 배열을 사용하여 각 노드의 부모 정보를 기록

### 또 다른 풀이

dfs를 활용한 풀이<br/>
- 인접 리스트를 구성
- 방문 체크로 순환을 방지
- dfs순회
    - 방문하지않은 인접노드(자식)를 순회하면서, 현재 노드를 부모로 설정
    - 루트 노드부터 시작
    
```js
const fs = require("fs");
const input = fs
  .readFileSync("./baekjoon/example.txt", "utf-8")
  .toString()
  .trim()
  .split("\n")
  .map((row) => row.split(" ").map(Number));
const [N] = input.shift();
const parents = new Array(N + 1).fill().map((_, i) => i);
const graph = Array.from({ length: N + 1 }, () => []);

for (let [a, b] of input) {
  graph[a].push(b);
  graph[b].push(a);
}

const visited = new Array(N + 1).fill(false);

const dfs = (node) => {
  visited[node] = true;

  for (let next of graph[node]) {
    if (!visited[next]) {
      parents[next] = node;
      dfs(next);
    }
  }
};

dfs(1);
for (let i = 2; i <= N; i++) {
  console.log(parents[i]);
}
```
