- start와 end모두 0부터 시작<br/>
- end는 문제의 조건(과일 종류의 수가 2이하)를 만족하는 최대 범위까지 증가 시킴<br/>
- 증가시킨 end에 대해서(start ~ end) 과일 종류의 수를 카운트함(map.size)
    > `arr.slice(...) + new Set(...)`을 이용할 경우 **시간 초과** 발생 -> `map 객체`를 이용해서 `과일 : 개수` 저장하여, `map.size(map의 키의 개수)`를 이용함<br/>
2. 그다음 start를 1증가 시켜, 이전 start의 과일을 제외한 새로운 경우의 수를 탐색한다.<br/>
- start를 증가시키기전에 현재 과일을 map에서 cnt-1한다. 만약 cnt가 0이하라면 해당 키를 맵에서 제거한다.<br/><br/>

### 대표적인 투포인터 문제
<br/>
1. 두 수의 합 (Two Sum) - 정렬된 배열<br/>
정렬된 배열에서 두 수의 합이 특정 값이 되는 쌍이 있는지 판단하는 문제

```js
function twoSum(arr, target) {
  let left = 0;
  let right = arr.length - 1;

  while (left < right) {
    const sum = arr[left] + arr[right];

    if (sum === target) {
      return [arr[left], arr[right]];
    } else if (sum < target) {
      left++;
    } else {
      right--;
    }
  }

  return null; // 없으면 null
}
```
console.log(twoSum([1, 2, 3, 5, 9], 8)); // [3, 5]<br/>
<br/>
2. 부분 합 구간 찾기 (연속된 수들의 합)<br/>
양의 정수 배열에서 연속된 부분 합이 target 이상이 되는 가장 짧은 구간의 길이를 구하는 문제
(백준 1806 부분합 문제와 동일)

```js
function minSubarrayLength(target, arr) {
  let start = 0, end = 0, sum = 0;
  let minLength = Infinity;

  while (end < arr.length) {
    sum += arr[end];
    end++;

    while (sum >= target) {
      minLength = Math.min(minLength, end - start);
      sum -= arr[start];
      start++;
    }
  }

  return minLength === Infinity ? 0 : minLength;
}
```
console.log(minSubarrayLength(7, [2, 3, 1, 2, 4, 3])); // 2<br/>

3. 고유 원소 2개 이하인 가장 긴 부분 배열
(현재 문제)
```js
function longestSubarrayWithMax2Types(arr) {
  let start = 0, end = 0;
  let countMap = new Map();
  let answer = 0;

  while (end < arr.length) {
    countMap.set(arr[end], (countMap.get(arr[end]) || 0) + 1);
    end++;

    while (countMap.size > 2) {
      countMap.set(arr[start], countMap.get(arr[start]) - 1);
      if (countMap.get(arr[start]) === 0) {
        countMap.delete(arr[start]);
      }
      start++;
    }

    answer = Math.max(answer, end - start);
  }

  return answer;
}
```
