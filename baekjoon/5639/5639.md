### 문제풀이

재귀를 이용해 트리 구조를 map자료구조의 형태로 저장하고, 후위 순회의 결과를 출력하는 문제이다.<br/>
순회(전위, 중위, 후위)의 결과가 주어지고, 트리 구조를 저장해야할 때, 항상 `root를 기준`으로 `value값의 위치`를 찾아나간다.<br/>
순회 결과의 값들을 순차적으로 돌면서 항상 root를 기준으로 시작해서 작으면 왼쪽으로, 크면 오른쪽으로 내려가면서 자신의 위치를 찾는다.<br/>

> `insertNode`를 시작하기 전에 `root : [null, null]`을 미리 트리에 저장하는 것이 좋다. 트리의 요소가 하나일 경우 `for(let i=1)`로 시작하는 순회를 하지 못한다.

> root를 기준으로 value를 추가하면서 그 value를 트리의 새로운 노드로 바로 설정해야한다.<br/>
```js
const insertNode = (root, value) => {
  const [left, right] = tree.get(root);

  if (value < root) {
    if (left === null) {
      //왼쪽자식
      tree.get(root)[0] = value;
      tree.set(value, [null, null]);
    } else {
      //이미 왼쪽자식이 있다면
      insertNode(left, value); //왼쪽자식의 자식으로 삽입
    }
  } else {
    if (right === null) {
      tree.get(root)[1] = value;
      tree.set(value, [null, null]);
    } else {
      insertNode(right, value);
    }
  }
};
```
```
Map(9) {
  50 => [ 30, 98 ],
  30 => [ 24, 45 ],
  24 => [ 5, 28 ],
  5 => [ null, null ],
  28 => [ null, null ],
  45 => [ null, null ],
  98 => [ 52, null ],
  52 => [ null, 60 ],
  60 => [ null, null ]
}
```
만약 위 코드가 아닌 아래 코드로 실행한다면 
```js
const insertNode = (root, value) => {
  if (!tree.has(root)) tree.set(root, [null, null]);

  const [left, right] = tree.get(root);

  if (value < root) {
    if (left === null) {
      tree.get(root)[0] = value;
      //   tree.set(value, [null, null]);
    } else {
      insertNode(left, value);
    }
  } else {
    if (right === null) {
      tree.get(root)[1] = value;
      //   tree.set(value, [null, null]);
    } else {
      insertNode(right, value);
    }
  }
};
```
60이라는 마지막 `리프노트`는 52의 오른쪽 자식으로는 설정이 됐지만, `node자체로써 tree에 추가가 안됐기 때문에` 순회 결과를 출력할때(console.log(node)) 해당 노드가 없게된다.
