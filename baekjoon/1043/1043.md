### 문제풀이

인접노드의 리스트가 필요하다.<br/>

### 첫번째 풀이 : 틀림

각 파티별로 파티에 오는 사람을 파악해서, 만약 그 중에 진실을 아는 사람이 포함돼있다면, 그 파티에있는 모든 사람들은 진실을 말해야하는 대상이 된다.<br/>

```js
for (let [num, ...people] of input) {
  const include = people.some((el) => tOrF[el]); //하나라도 true면 true를 반환
  if (include) {
    for (let p of people) {
      tOrF[p] = true;
    }
  }
}
```

하지만 이것은 파티 순서에따라 결과가 달라진다.<br/>

### 반례
```js
5 4
1 5
2 1 2
2 2 3
2 3 4
2 4 5
```

- 5번은 진실을 말해야하는 대상이다.<br/>
- 5번과 같이 온 4, 4번과같이 온 3, 3번과 같이 온 2 ... 1,2,3,4,5 모두 진실을 말해야하는 대상이된다.<br/>
- 하지만 내코드에선 파티를 순서대로 돌면서 진실을 말해야하는 대상을 설정하기 때문에 4,5만 진실대상으로 설정된다.<br/>
  > 4, 5가 묶여있다는 것을 나중에 알 수 있기 때문에 결과에 오류가 생긴다.<br/>

### 수정된 풀이 : 인접리스트 활용용

파티를 순회하면서 각 참여자와 `같이오는 참여자 리스트`(`인접노드 리스트`)를 🌟우선 파악해야한다.<br/>
`진실을 말해야하는 대상 리스트` : `trues`를 순회하면서 서로 인접한(묶여있는) 참여자들의 진실/과장 여부를 설정한다.<br/>

```js
const trues = []; //진실을 말해야하는 대상 리스트
const adjList = new Array(N + 1).fill().map(() => []);

for (let p of arr) {
  tOrF[p] = true;
  trues.push(p);
}

//인접리스트 설정
for (let [num, ...people] of input) {
  for (let i = 0; i < num; i++) {
    const currP = people[i];
    const remain = [...people.slice(0, i), ...people.slice(i + 1)];
    adjList[currP].push(...remain);
  }
}

let index = 0;
while (index < trues.length) {
  const p = trues[index]; //진실을 말해야하는 대상 p

  for (let nP of adjList[p]) {
    //p와 인접한 nP들
    if (!tOrF[nP]) {
      //과장으로 설정돼있다면 진실로 설정하고, trues 배열에 추가
      tOrF[nP] = true;
      trues.push(nP);
    }
  }

  index++;
}
```

최종 count : 과장을 이야기해도 되는 파티의 수<br/>

```js
let count = 0;

//num: 각 파티마다 오는 사람의 수, people: 각 파티마다 오는 사람들의 번호가 담긴 배열
for (let [num, ...people] of input) {
  let result = people.every((el) => !tOrF[el]); //모두 과장을 이야기해도 되는 사람들인 경우
  if (result) count++;
}
```
