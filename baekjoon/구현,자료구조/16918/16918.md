### 문제풀이

반복되는 규칙을 기반으로 구현하는 문제<br/>
- N이 1일 경우, 초기상태 board(init) 그대로 반환
- N이 2일 경우, 나머지칸 폭탄설치 후, 폭탄으로 가득찬 board 반환
- N이 3일 경우, init을 기준으로 폭탄이 터진 board 반환
    - init을 기준으로 터지는 위치를 toClear에 저장 -> 인접한 구역도 저장
- N이 4일 경우, 3의 board에서 빈 공간이 폭탄으로 가득찬 board 반환
- N이 5일 경우, 3을 기준으로 폭탄이 터진 board 반환
    - 3의 board를 기준으로 터지는 위치를 toClear에 저장
- N이 6일 경우 == 4일 경우 == 2일 경우
- N이 7일 경우 == 3일 경우
- N이 8일 경우 == 4일 경우 == 2일 경우
- N이 9일 경우 == 5일 경우
...<br/>

✳️ CASE가 `init`, `full`, `A`, `B` 총 4가지로 구분된다.<br/>
