### 문제풀이

여러구간의 일정들에 대해, 연속되는 일정의 각 구간의 면적의 합<br/>
1. 달력에 일정을 표시<br/>
- 캘린더 배열 : 1차원<br/>
    - 세로로 확장할 필요x -> 배열의 각 요소(해당 날짜)에 겹치는 일정들이 모두 카운트됨<br/>
    - 캘린더를 한 줄로 압축<br/>

2. 날짜별로 순회하면서 끊기는 부분을 기준으로 각 달력 구간의 면적 구하기<br/>
- 특정날짜 day의 calendar[day]값 > 0 <br/>-> 현재까지 이어진 면적의 구간을 이어나간다. -> width ++, height는 해당 구간의 최대값으로 설정<br/>
- calendar[day] === 0 -> 구간이 끊김 -> 정답에 면적더하기, width, height는 0으로 초기화<br/>
