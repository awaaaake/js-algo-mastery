### 문제풀이

트리의 지름 : 트리에서 두 노드간의 가장 긴 경로<br/>
문제해결과정<br/>
이 문제는 DFS(깊이 우선 탐색)를 두 번 사용하여 트리의 지름을 구할 수 있다.

1. dfs 탐색
   한 노드에서 시작해 가장 먼 노드를 찾고(👉트리의 가장 끝부분으로 젤 먼곳까지 이동한 다음), 그 노드를 시작점으로 다시 dfs를 하여 가장 먼 노드까지의 거리를 구하면, 그 거리가 트리의 지름이다.
2. 그래프 구조
   인접리스트 방식으로 트리의 각 노드와 간선정보를 저장한다

> 💡 인접리스트
그래프나 트리와 같은 자료구조에서 각 노드가 인접한(연결된)노드들을 리스트 형태로 저장하는 방식이다. <br>

인접 리스트 구현 (JavaScript)
```js
1 - 2
|   |
3 - 4
 \
  5

1: [2, 3]
2: [1, 4]
3: [1, 4, 5]
4: [2, 3]
5: [3]

// 노드와 연결된 노드 정보를 저장할 인접 리스트
map, 객체, 배열
const graph = {
  1: [2, 3],
  2: [1, 4],
  3: [1, 4, 5],
  4: [2, 3],
  5: [3],
};

// 노드 1과 연결된 노드 출력
console.log(graph[1]); // [2, 3]
```
