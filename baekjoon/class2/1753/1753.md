### 문제풀이
### 다익스트라 알고리즘
그래프에서 주어진  `시작 노드에서, 모든 다른 노드로 가는 최단경로를 찾는 알고리즘`이다. -> 이 알고리즘은 `간선 가중치가 모두 양수인 경우`에만 사용할 수 있다.

### 알고리즘 주요과정
1. 시작노드에서 다른 모든 노드까지 거리를 무한대로 설정
2. 아직 방문하지않은 노드들 중에서, `시작 노드로부터 거리가 가장 짧은 노드`를 선택(이때 우선순위 큐: 최소힙 사용)
3. 선택한 노드 방문처리 -> `그 노드와 연결된 모든 노드`의 거리를 갱신
4. 이 과정을 모든 노드가 방문될 때까지 반복

### 최소힙
최소 거리의 노드를 추출할 때, 우선순위 큐의 자료구조는 최소힙이다.

### 만약 힙 자료구조를 쓰지않고, 배열형태의 우선순위 큐를 사용했다면?
```js
const fs = require("fs");

// 입력 처리
const input = fs.readFileSync("/dev/stdin").toString().trim().split("\n");
const [V, E] = input[0].split(" ").map(Number);
const start = Number(input[1]);

const graph = Array.from({ length: V + 1 }, () => []);
for (let i = 2; i < input.length; i++) {
  const [u, v, w] = input[i].split(" ").map(Number);
  graph[u].push([v, w]);
}

const dijkstra = (start) => {
  const distances = Array(V + 1).fill(Infinity);
  distances[start] = 0;

  const pq = [];
  pq.push([0, start]); // [distance, node]

  while (pq.length > 0) {
    // 최소 거리 노드 추출
    pq.sort((a, b) => a[0] - b[0]); // 거리 기준으로 정렬 -> 매번 정렬해야함O(ELogE)
    const [currentDist, currentNode] = pq.shift();

    // 이미 처리된 경우 스킵
    if (currentDist > distances[currentNode]) continue;

    for (const [nextNode, weight] of graph[currentNode]) {
      const newDist = currentDist + weight;

      if (newDist < distances[nextNode]) {
        distances[nextNode] = newDist;
        pq.push([newDist, nextNode]);
      }
    }
  }

  return distances;
};

const distances = dijkstra(start);

// 출력
let result = "";
for (let i = 1; i <= V; i++) {
  result += distances[i] === Infinity ? "INF\n" : distances[i] + "\n";
}
console.log(result);
```
