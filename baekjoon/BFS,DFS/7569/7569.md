### 문제풀이

방향이 6개이고, 3차원 배열을 활용하는 bfs 문제이다.<br/>
2차원 배열 선언 방식<br/>
```js
Array.from({ length: N }, () => Array(M).fill(0)); //N행 M열
```

3차원 배열 선언 방식<br/>
```js
Array.from({ length: H }, () =>
  Array.from({ length: N }, () => Array(M).fill(0))
);
//높이 H, N행, M열
```
익은 토마토들의 위치와 안익은 토마토들의 개수를 확인한다.<br/>
익은 토마토들을 돌면서 direction에 따라 안익은 토마토들의 위치를 확인한다.<br/>
현재 익은 토마토들의 위치를 모두 확인했고, 다음 안익은 토마토의 위치가 있으면 day+하고, 익힌 토마토 개수를 unripe에서 -하고, queue를 다시 (현재 익은 토마토기준으로) 다음으로 익힌 토마토들로 설정한다.<br/>
while문을 다돌고 나면 안익은게 하나라도 있으면 -1 리턴하고, 그게 아니라면 days를 리턴한다.<br/>
(⚠️처음에 안익은 토마토가 없을 수도 있기 때문에 bfs를 돌기전에 unripe를 확인할 필요가 있다.)
