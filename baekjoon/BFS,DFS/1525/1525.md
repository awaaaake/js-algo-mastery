### 문제풀이

입력으로 주어진 시작상태에서 목표상태 '123456780'을 만들기위한 최소이동횟수 => swap 횟수<br/>

1. start와 target 상태를 정의한다.<br/>
2. 현재의 상태 cur를 기준으로 다음 상태를 queue에 추가한다.<br/>
    - 현재 상태 cur를 x,y 좌표값으로 변경한다.<br/>
    - x,y의 좌표값을 기준으로 이동가능한 nx,ny를 구한다.(방문한적x, 범위 내)<br/>
    - 현재 0의 위치의 값과(zero), (nx,ny)를 기준으로한 다음 위치(nextIdx)의 값을 swap<br/>
    - 방문표시와 함께 큐에 [next, cnt+1]을 추가한다.<br/>

> 💡3*3의 배열을 일렬의 문자열로 표시했을 때, 배열의 각 위치가 문자열의 인덱스로 전환된다. `ex) (1,2) => 1*3 + 2 = 5`<br/>
