### 문제풀이

비의 높이에 따른 안전한 영역의 개수 구하기<br/>
1. 비의 양에 따른 높이는 `최소 0`부터 board상 `지역의 max높이 -1`<br/>
- max 높이는 고려x -> 모두 잠기는 것은 어차피 안전영역의 개수가 0<br/>
- 비의 양이 적게 온다고 안전영역의 개수가 많은것이 아니다.
- 비가 너무 적게 오면 안전영역이 하나로 넓게 설정되어, 결국 너무 적게와도 많이와도 안된다.<br/>
2. 기준이되는 비의 양에 맞게 dfs로 안전영역의 갯수를 구한다.<br/>
- 그중 max값을 찾는다<br/>


### DFS로 연결된 영역의 개수 구하기 – 공통 구조 공식
- board 전체 위치를 순회하면서 방문하지 않은 곳에 cnt++(영역의 개수)와 함께 dfs로 순회하여 연결된 모든 지역을 방문 표시한다<br/>

```js
// 1. 보드, 방문 배열 정의
const visited = Array.from({ length: N }, () => Array(M).fill(false));

// 2. 방향 배열 (상하좌우)
const dx = [0, 0, -1, 1];
const dy = [-1, 1, 0, 0];

// 3. DFS 함수 정의
function dfs(x, y) {
  visited[x][y] = true;

  for (let dir = 0; dir < 4; dir++) {
    const nx = x + dx[dir];
    const ny = y + dy[dir];

    if (
      nx >= 0 && nx < N &&
      ny >= 0 && ny < M &&
      !visited[nx][ny] &&
      board[nx][ny] === 유효한값 // 예: 1 또는 잠기지 않은 곳 등
    ) {
      dfs(nx, ny);
    }
  }
}

// 4. 전체 순회하며 DFS 호출
let count = 0;
for (let i = 0; i < N; i++) {
  for (let j = 0; j < M; j++) {
    if (!visited[i][j] && board[i][j] === 유효한값) {
      dfs(i, j); // 하나의 영역을 다 방문
      count++;   // 영역 하나 추가
    }
  }
}

// 5. count가 연결된 영역의 개수
console.log(count);
```
