### 문제풀이

1. dfs를 통해 (방)영역의 개수와 크기를 구한다.<br/>

- 모든 좌표 (i,j)를 순회하면서 방번호가 지정되지않았다면(=방문하지 않았다면), 방문 표시와 함께 연결된 모든 방들을 방문한다.
  - 이때, 방문하는 연결된 영역에는 같은 roomNum를 표시한다.
- 특정 좌표에서 이동 가능한 4가지 방향을 따질 때, 현재 board[i][j]의 값을 2진수로 변환하여, ex.`1001` 이동가능한 방향을 따진다.
  - 십진수.toString(2) -> 10진수를 2진수로 변환하는 함수
  - string.padStart(4, '0') -> 대상 문자열을 목표하는 길이(4)만큼 나머지 시작 부분을 '0'으로 채운다.<br/>

2. 모든 좌표의 방번호와, 방 번호별 사이즈가 결정되었다면, 다시 모든 좌표를 순회하면서 다른 영역과 그 크기를 합치는 경우를 따져본다.

- 모든 좌표를 순회하며, 현재 영역의 4가지 방향으로 연결된 다른 영역(다른 번호의 방)의 사이즈를 통해 `하나의 벽을 제거하여 얻을 수 있는 가장 넓은 방의 크기`의 maxSum을 구한다.

```js
const fs = require("fs");
const input = fs
  .readFileSync("./baekjoon/example.txt", "utf-8")
  .toString()
  .trim()
  .split("\n")
  .map((row) => row.split(" ").map(Number));

/**
 * 이 성에 있는 방의 개수
   가장 넓은 방의 넓이
   하나의 벽을 제거하여 얻을 수 있는 가장 넓은 방의 크기
 */

const [N, M] = input[0];
const board = input.slice(1, M + 1);
const dir = [
  [+1, 0],
  [0, 1],
  [-1, 0],
  [0, -1],
];

//dfs
const visited = Array.from({ length: M }, () => new Array(N).fill(0));
let size = 0;
let roomNum = 0;
const dfs = (x, y) => {
  visited[x][y] = roomNum;
  //1111 => 남,동,북,서
  const num = board[x][y];
  const binaryNum = num.toString(2).padStart(4, "0").split("").map(Number);

  for (let i = 0; i < 4; i++) {
    if (binaryNum[i] === 0) {
      const nx = x + dir[i][0];
      const ny = y + dir[i][1];

      if (nx >= 0 && nx < M && ny >= 0 && ny < N && !visited[nx][ny]) {
        size++;
        dfs(nx, ny);
      }
    }
  }
};

let cnt = 0;
const sizes = [0];
for (let i = 0; i < M; i++) {
  for (let j = 0; j < N; j++) {
    if (!visited[i][j]) {
      cnt++;
      roomNum++;
      size = 1;

      dfs(i, j);
      sizes.push(size);
    }
  }
}

let maxSum = 0;
for (let i = 0; i < M; i++) {
  for (let j = 0; j < N; j++) {
    for (let k = 0; k < 4; k++) {
      const ni = i + dir[k][0];
      const nj = j + dir[k][1];
      if (ni >= 0 && ni < M && nj >= 0 && nj < N) {
        const currNum = visited[i][j];
        const nextNum = visited[ni][nj];
        if (currNum !== nextNum)
          maxSum = Math.max(maxSum, sizes[currNum] + sizes[nextNum]);
      }
    }
  }
}

console.log(cnt);
console.log(Math.max(...sizes));
console.log(maxSum);
```


### 개선된 풀이
- `dfs`대신 `bfs`를 사용
`2진수 문자열 변환`을 없애고, `비트마스크로 직접 체크하는 방식`으로 개선할 수 있다.

```js
const fs = require("fs");

const raw = fs.readFileSync(0, "utf8").trim().split("\n").map(r => r.split(" ").map(Number));

const [N, M] = raw[0];               // N: 행(세로), M: 열(가로)
const board = raw.slice(1, 1 + N);   // N줄만 가져오기

// 벽 비트 (문제 정의): 서(1), 북(2), 동(4), 남(8)
const DIRS = [
  [0, -1],  // W
  [-1, 0],  // N
  [0, 1],   // E
  [1, 0],   // S
];
const MASKS = [1, 2, 4, 8];

const visited = Array.from({ length: M }, () => Array(N).fill(0));
const sizes = [0]; // roomId -> 방 넓이
let roomId = 0;

// 한 방 BFS로 칠하고 넓이 반환
const bfs = (sr, sc, id) => {
  const q = [[sr, sc]];
  visited[sr][sc] = id;
  let size = 1;

  for (let qi = 0; qi < q.length; qi++) {
    const [r, c] = q[qi];
    const cell = board[r][c];

    for (let d = 0; d < 4; d++) {
      // 벽이 없으면 이동 가능
      if ((cell & MASKS[d]) === 0) {
        const nr = r + DIRS[d][0];
        const nc = c + DIRS[d][1];
        if (nr >= 0 && nr < M && nc >= 0 && nc < N && visited[nr][nc] === 0) {
          visited[nr][nc] = id;
          q.push([nr, nc]);
          size++;
        }
      }
    }
  }
  return size;
};

// 1) 방 개수와 각 방 넓이 계산
for (let r = 0; r < M; r++) {
  for (let c = 0; c < N; c++) {
    if (visited[r][c] === 0) {
      roomId++;
      sizes[roomId] = bfs(r, c, roomId);
    }
  }
}

const numRooms = roomId;
const maxRoom = Math.max(...sizes);

// 2) 하나의 벽을 제거했을 때 최대 넓이
// 중복 제거 위해 동/남 방향만 본다
let maxJoin = 0;
for (let r = 0; r < M; r++) {
  for (let c = 0; c < N; c++) {
    const a = visited[r][c];

    // 동(E)
    if (c + 1 < N) {
      const b = visited[r][c + 1];
      if (a !== b) maxJoin = Math.max(maxJoin, sizes[a] + sizes[b]);
    }
    // 남(S)
    if (r + 1 < M) {
      const b = visited[r + 1][c];
      if (a !== b) maxJoin = Math.max(maxJoin, sizes[a] + sizes[b]);
    }
  }
}

console.log(numRooms);
console.log(maxRoom);
console.log(maxJoin);
```

- 네 방향의 벽 여부를 비트로 확인한다.

| 방향      | 값  | 비트 위치(2진수) |
| --------- | --- | ---------------- |
| 서(West)  | 1   | 0001             |
| 북(North) | 2   | 0010             |
| 동(East)  | 4   | 0100             |
| 남(South) | 8   | 1000             |

즉, 어떤 칸의 값이 5(2진수 0101)이면<br/>
서쪽(1) 비트: 1 → 벽 있음<br/>
북쪽(2) 비트: 0 → 벽 없음<br/>
동쪽(4) 비트: 1 → 벽 있음<br/>
남쪽(8) 비트: 0 → 벽 없음<br/>

- 비트마스크는 비트 AND 연산자(&)로 특정 방향에 벽이 있는지 확인할 수 있다.

### DFS/BFS
- 연결된 영역의 크기를 구할 땐 DFS/BFS 모두 가능
- DFS대신 BFS를 추천하는 이유는 : BFS는 재귀를 안쓰고 반복문으로 구현 -> 스택 오버플로우 위험이 없다.

**BFS를 이용하여 연결된 영역의 크기를 구하는 방법(예시)**
- 1은 방문한 칸, 0은 아직 미방문 칸.
```ini
S 0 0
0 0 0
0 0 0
```
**BFS 단계별**

(1) 큐 초기화
```ini
Q = [S]
방문[S] = true
```

(2) 큐에서 S 꺼내고 인접 칸 넣기
```ini
Q = [ (S인접1), (S인접2), ... ]
```

(3) 인접 칸 하나 꺼내서 다시 그 인접 칸 넣기
```ini
Q = [ (다음 칸들...), ... ]
```

(4) 큐가 빌 때까지 반복
결국 시작점과 연결된 모든 칸이 한 번씩 큐에 들어갔다 나옴
방문 표시 덕분에 중복 없이 전부 탐색 완료

```JS
// 1) 방 개수와 각 방 넓이 계산
for (let r = 0; r < N; r++) {
  for (let c = 0; c < M; c++) {
    if (visited[r][c] === 0) {
      roomId++;
      sizes[roomId] = bfs(r, c, roomId);
    }
  }
}
```
