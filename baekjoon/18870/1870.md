### 문제풀이

숫자배열을 set으로 압축한 다음, 정렬(sort)한 새로운 배열(numSet)을 구한다.<br/>
숫자배열을 순회하면서 각 숫자의 numSet의 인덱스를 구하면, 그 인덱스는 곧 자신보다 작은 수들의 개수가 된다.<br/>
이때, 정렬한 새로운 배열(numSet)에서 각 수의 인덱스(위치)를 dic로 기억해두고, 숫자배열을 순회하면서 답을 구할때 indexOf가 아니라 미리 정의해둔 dic를 사용해야한다.(시간단축의 핵심 - 중복되는 수의 경우 불필요하게 indexOf로 순회)

> 주의할 점<br/>
sort함수로 숫자를 정렬할땐 ((a,b) => a-b)를 꼭 추가해야한다. 또한 sort함수는 원본 배열 자체를 수정하기 때문에 원본배열을 건드리지 않아야하는 경우, 반드시 배열을 먼저 복제한 후 사본을 상대로 정렬해야한다.
```js
const nums = [3, 1, 2];
const sortedNums = [...nums].sort();
console.log({ nums, sortedNums });
```
toSorted()함수를 사용하면 원본 배열을 건드리지않고 정렬된 배열 사본을 바로 얻을 수 있다.
```js
const nums = [3, 1, 2];
const sortedNums = nums.toSorted();
console.log({ nums, sortedNums });
```
